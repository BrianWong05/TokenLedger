# Copilot Limits use the Source's internal Limits endpoint

GitHub Copilot's individual-plan Limit state is available to its own clients at `GET https://api.github.com/copilot_internal/user`, but GitHub does not document that route as a stable public API. The Copilot Companion may nevertheless read it on a person-initiated refresh under ADR-0019, using an existing Copilot or GitHub login without writing or refreshing the credential. It emits only Limit Readings with a finite entitlement and reset; on the current paid plan that means the Premium Requests limit, while unlimited Chat and Completions do not render as Limits. The response is parsed through a strict allowlist of the plan, entitlement, remaining amount, and reset fields. A missing or changed field produces no new Limit Reading and renders refresh unavailable rather than guessing. This accepts a contained maintenance risk to provide the requested current gauge without scraping a CLI or weakening the meaning of Limit.
